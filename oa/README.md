# Demo OA Frontend

Vue 3 and TypeScript administration interface for the public Demo OA showcase.

```bash
cp .env.example .env
pnpm install
pnpm dev
```

The UI covers employees, departments, assets, IT accounts, form design,
approvals, workflows, and access-control administration.

This frontend was developed on top of the MIT-licensed SoybeanAdmin project.
See `LICENSE` and the repository-level `NOTICE.md` for attribution.
